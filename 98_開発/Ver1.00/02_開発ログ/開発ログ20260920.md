## 2. 本日の決定事項・進捗内容

### ① 「AIMD（AI Markdown Project）」フォルダ構成仕様の確定
* **階層ルールと拡張子**:
  * 大項目（章）: `.aimd-chapter`、中項目（節）: `.aimd-section`、第3階層以降の小項目: すべて `.aimd-subsection`
  * ファイル内での見出しタグ（`#`, `##`）による章立ても許容
* **目次・前書きナンバリング**:
  * 章配下の `index.md` は廃止し、ルート直下に集約
  * 前書き（`00-初めに.md` / `00-Introduction.md`）の有無に応じた目次（`00-index.md` または `01-index.md`）および章連番の自動同期ルールを策定
* **メタデータ（`.aimd-meta/`）の保護**:
  * `manifest.yaml`、`AI_CONTEXT.md`、`AI_RULES.md` は隠しフォルダ内でAIが自動管理
  * 完全非表示にはせず、ツリー上の「🔒（鍵）」アイコン表示、開いた際の**Read-Only（読取専用）モード強制**、上部警告バナー、手動保存時の確認ダイアログによる保護方針を決定
* **画像管理（`99-Image/`）**:
  * 章固有画像は紐づく親章の `99-Image/`、共通画像は親階層の `99-Image/` に配置
  * 命名規則（`XX-ファイル名_figYY_(入力名称).png`）と入力ポップアップ、未使用画像の一括削除コマンド仕様を確定

### ② VS Code拡張機能「AIMD Studio」要件定義（パート2）のブラッシュアップ
* **動作モードの自動切り替え**:
  * ワークスペースのルート名が `.aimd` か否かで「AIMDモード」と「通常モード」を切り替え
* **エディタUI・編集支援**:
  * 標準TextEditor＋装飾APIベース
  * GFM準拠の改行（末尾半角スペース2つ）自動付与
  * インラインHTMLタグ出力によるスタイルコントロールパネル（太さ・色・サイズ）
  * スラッシュコマンド（`/`）およびインラインミニバーによるテーブルエディタ
* **ハーネスAI連携 & Markdown Preview Diff**:
  * VS Code Language Model API（Copilot等）と連携し、AIの入力を `.aimd-meta/` 内のルールで厳密に拘束（ハーネス制御）
  * レンダリング後の画面で変更箇所を可視化する「Markdown Preview Diff（薄緑・薄赤ハイライト）」を採用
  * メタデータはAIが直接書き込まず、構成変更時に「更新通知」を出してユーザー承認後に直列更新（Mutex排他制御・バックアップ復元付き）
* **Git連携・変換機能**:
  * SCMビュー内での章・節別差分グループ化、`ai/<日時>-<章名>-<概要>` ブランチの自動作成
  * 既存プロジェクトのAIMD化コマンド（標準リネームモード / AI支援変換モード）を定義
* **外部仕様の調整**:
  * SharePoint共有に関する記述を全ドキュメントから完全除外

### ③ ユースケース・システムフローの図解化（Mermaid）
要件定義書に以下の図解を統合・更新：
1. **全体ユースケース図**

3. **画像貼り付け・保存先自動解決フロー**
4. **AIディスカッションとMarkdown Preview Diff反映フロー**
5. **ファイル追加・目次自動同期フロー**
6. **既存プロジェクトのAIMD変換フロー**
