# MarkdownProject
Markdownを章単位で分割管理・編集できるVS Code拡張機能。ユーザーには見通しが良く快適な執筆体験を提供し、生成AIにはコンテキストの局所化による高精度かつ干渉のない編集を実現します。長文ドキュメントの執筆を、人とAIのシームレスな協調でスマートに支援します。
